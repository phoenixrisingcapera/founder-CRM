# Legacy CRM Material

This folder contains archived planning material and non-canonical CRM source material.

## What belongs here

- stale planning docs
- DDDecks-specific CRM notes
- old admin console planning
- abandoned route notes
- duplicated or superseded product thinking

## What does not belong here

- active `web/` and `api/` implementation
- current Founder CRM product decisions
- the Founder CRM Grill

## Important

Some old code still lives outside this folder in `deck-crm/` and `deck-admin-crm/` because it is being treated as extraction source material. Those directories are reference surfaces, not the canonical product.
