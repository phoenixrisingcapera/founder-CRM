# deck-crm Reference Surface

This is not the canonical AiStack Founder CRM product.

It is a source-material surface that contains useful ideas for:
- telemetry
- admin visibility
- failure tickets
- provider health
- quota visibility
- deck upload and workflow proxy patterns

Do not add new founder CRM product features here unless the work is explicitly an extraction or migration task.

Canonical founder CRM surfaces live in:
- `../web`
- `../api`
